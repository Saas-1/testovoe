# Тестовое задание в одну хорошую компанию

## Для запуска проекта использовать

docker-compose up

# Основной функционал

POST /add-person: Добавить человека

DELETE /delete-person?id=: Удалить человека

PUT /update-person?id=: Обновить информацию о человеке

GET /name?name=&limit=&offset=: Получить человека по имени с пагинацией

GET /ascname?surname=&limit=&offset=: Отфильтровать людей по имени в порядке возрастания с пагинацией

GET /ascsurname?name=&limit=&offset=: Отфильтровать людей по фамилии в порядке возрастания с пагинацией

### Описание директорий

- **cmd/**: Содержит основную логику запуска приложения. Здесь находятся исполняемые файлы.
- **docs/**: Документация проекта, включая инструкции по использованию и настройке.
- **entities/**: Определение структур и моделей данных, которые используются в приложении.
- **internal/**: Внутренние пакеты, которые не должны быть доступны извне.
- **logger/**: Реализация логирования для приложения.
- **migrations/**: Скрипты и файлы миграций для работы с базой данных.
- **.env**: Файл для хранения переменных окружения.
- **docker-compose.yaml**: Файл конфигурации для развертывания приложения через Docker Compose.
- **Dockerfile**: Инструкции для сборки Docker-образа приложения.
- **go.mod**: Файл для управления зависимостями приложения, использующего Go.
