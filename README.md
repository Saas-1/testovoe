# Тестовое задание в одну хорошую компанию

## Для запуска проекта использовать:

docker-compose up

# Основной функционал

POST /add-person: Добавить человека
DELETE /delete-person: Удалить человека
PUT /update-person: Обновить информацию о человеке
GET /name: Получить человека по имени с пагинацией
GET /ascname: Отфильтровать людей по имени в порядке возрастания с пагинацией
GET /ascsurname: Отфильтровать людей по фамилии в порядке возрастания с пагинацией
